## 2025-05-18 - Non-intrusive Clipboard Utility in Lead Lists
**Learning:** In tabular outreach workflows where users send pre-generated messages, providing a one-click copy button next to message previews preserves workflow velocity for operators using desktop messaging apps without breaking row focus or navigation.
**Action:** Always maintain native button semantics, state debounce (`dataset.isCopying`), and bilingual/localized ARIA announcements with visual timeout resets.
