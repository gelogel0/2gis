## 2025-05-15 - Improving outreach efficiency with Copy-to-Clipboard

**Learning:** When users are performing manual outreach, reducing the number of clicks/keyboard actions is critical. A "Copy to Clipboard" button with immediate visual feedback ("✓ Скопировано!") significantly improves the flow compared to manual selection. Additionally, in Python-based HTML generation using `.replace()`, literal JavaScript braces must NOT be doubled (unlike in `.format()`), or they will result in syntax errors in the browser.

**Action:** Always provide a one-click copy action for generated content and ensure visual confirmation of success. When working with template-based HTML generation in Python, verify the substitution method (replace vs format) to handle braces correctly.
