# Palette's Journal

## 2026-07-08 - Copy to Clipboard & Accessibility
**Learning:** For a B2B outreach tool, "Copy to Clipboard" with immediate visual feedback (icon change) significantly improves the manual workflow. Accessibility requires explicit aria-labels on icon-only buttons and high-contrast :focus-visible states for dark themes.
**Action:** Always provide visual/aria feedback for async or background actions like clipboard copying. Use #4ade80 as the standard high-contrast focus color for this dark UI.
