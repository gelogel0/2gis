# Palette's Journal - LeadHunter MVP

This journal tracks critical UX and accessibility learnings discovered during the development of LeadHunter MVP.

## 2024-05-23 - Initial Setup
**Learning:** The project uses a dark-themed vanilla HTML/JS interface for manual WhatsApp outreach. Global event delegation is used for row actions.
**Action:** Ensure all new interactive elements (like the Copy button) are integrated into the existing global click listener and maintain the dark theme aesthetic.
