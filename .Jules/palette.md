## 2025-05-14 - [Copy to Clipboard Micro-UX]
**Learning:** For static HTML tools generating content from templates, users often need to extract generated text (like AI offers) for use in other applications. Adding a copy button with immediate visual feedback (icon change) significantly improves perceived responsiveness and usability.
**Action:** Always provide visual confirmation (e.g., icon change to ✅) and update ARIA labels when implementing clipboard actions to ensure the interaction is clear and accessible.
