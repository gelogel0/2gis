## 2026-06-25 - Copy Offer UX Pattern
**Learning:** Adding a copy-to-clipboard button with visual feedback (icon change and color highlight) significantly improves productivity for manual outreach tasks.
**Action:** Always include temporary visual confirmation (e.g., ✅) for clipboard actions.

## 2026-06-25 - Visual Feedback and Accessibility for Processed Rows
**Learning:** Applying `pointer-events: none` to primary action buttons in a processed row (e.g., "Send", "Mark Sent") prevents redundant clicks while maintaining context.
**Action:** Use CSS to selectively disable interaction on primary actions in completed states while keeping utility actions (like "Copy") interactive.
