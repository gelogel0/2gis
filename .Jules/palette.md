## 2025-02-15 - Focus Indicators on Dark Theme Interfaces
**Learning:** For dark-theme interfaces (backgrounds like `#0e1116`), default browser focus indicators are often low-contrast or completely invisible, creating a barrier for keyboard users. Utilizing `:focus-visible` with a high-contrast green indicator (`#4ade80`) provides clear and beautiful feedback without interfering with mouse-user experiences.
**Action:** Always styling interactive elements with a distinct, high-contrast `:focus-visible` outline when working with custom dark-themed templates.
