## 2025-05-15 - Improving outreach efficiency with Copy-to-Clipboard

**Learning:** In lead generation tools, users often need to manually copy personalized messages for different platforms or for double-checking before sending. Providing a one-click copy button with visual feedback significantly reduces friction.

**Action:** Always include a "Copy to Clipboard" utility with an icon-state change (e.g., 📋 -> ✓) for long generated texts in outreach interfaces.

## 2025-05-15 - Enhancing keyboard navigation for rapid workflows

**Learning:** Power users often prefer keyboard navigation for repetitive tasks like going through a lead queue. Without clear `:focus-visible` styles, the interface is inaccessible to these users and screen reader users alike.

**Action:** Implement high-contrast `:focus-visible` rings and semantic `aria-labels` for all action-oriented buttons and inputs in data-intensive dashboards.
