## 2025-02-15 - Async State Update Rollback & Clipboard A11y
**Learning:** For asynchronous interactions (like marking an item as sent) that update backend state via REST, optimistically modifying the UI improves perceived responsiveness. However, to keep the application accessible and prevent out-of-sync states, any failure must trigger a clean rollback of the modified CSS classes, counters, and disabled attributes. Additionally, clipboard copy actions must use native buttons with clear, temporary icon changes and ARIA label announcements to keep screen reader users in context.
**Action:** Always capture initial UI states (labels, ARIA tags, classes) prior to asynchronous operations or clipboard copying, and provide a 2000ms timeout rollback on errors or to reset copy success states. Keep text selectable by disabling interactive buttons natively rather than disabling pointer events on entire containers.
