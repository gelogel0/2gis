## 2026-08-06 - Copy to Clipboard Verification & Template Substitution in Sandboxed Environments
**Learning:** In a headless browser environment (such as Playwright), the Clipboard API (`navigator.clipboard`) is disabled by default and restricted only to Secure Contexts. To successfully verify clipboard features, files must be served over a secure/local origin (e.g., using Python's `http.server`) rather than `file://` URLs, and the browser context must be explicitly granted `clipboard-read` and `clipboard-write` permissions. Furthermore, when generating HTML containing native JavaScript blocks with double-braces `{{ }}` template constraints, a final replace mapping `{{` and `}}` to single braces is required to avoid syntax errors in the browser.
**Action:** When verifying any future clipboard feature using Playwright, always spin up a temporary python HTTP server and configure `permissions=["clipboard-read", "clipboard-write"]` on the browser context. Always verify that double-braced template literals are correctly processed into standard JavaScript single braces before serving.
