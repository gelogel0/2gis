## 2025-01-20 - Adding Accessible Copy-to-Clipboard Functionality
**Learning:** Adding a copy-to-clipboard action button to a table element with multi-line text improves the reachability of text outreach offers. When using non-text icon buttons (e.g., 📋), ensuring a proper screen reader descriptive attribute (e.g., `aria-label`) in the matching local language avoids visual clutter while staying accessible. Adding an anti-race condition guard with `dataset.isCopying` ensures high interactivity without timeout feedback loops overlapping on rapid clicks.
**Action:** When implementing any context-dependent feedback action (like copying), wrap the text and actions in a flexbox container with standard-aligned styling, disable multiple concurrent click events via state/dataset properties, and update both visual text and screen reader labels appropriately during feedback intervals.
