## 2025-02-21 - [Copy Offer Clipboard API & Double Braces]
**Learning:** Browser environments restrict `navigator.clipboard.writeText` in non-Secure Contexts (like local `file://` URIs). To run automated/integration tests in Playwright or manual testing correctly without browser permission blocks, pages should be hosted over a Secure Context (e.g., localhost over HTTP server) and permissions explicitly granted. Additionally, when HTML templating uses Python string replacements where the raw template uses double curly braces `{{` to escape style/js blocks, the build script must explicitly replace `{{` and `}}` with `{` and `}` before writing to disk, otherwise JavaScript execution fails with SyntaxError.
**Action:** Always verify Clipboard API interactions by hosting files over a local web server (using `http.server` or similar) in tests and setting browser permissions, and ensure double curly braces are resolved to single ones in written build output.
