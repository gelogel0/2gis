# Palette's Journal 🎨

## 2025-05-14 - Initial UX Audit of Send Queue
**Learning:** The current "Send Queue" interface is functional but lacks basic accessibility (ARIA labels) and utility features like "Copy to Clipboard" for the generated offers, which hinders the workflow if the user needs to manually edit or move the text. External links are also missing security/privacy attributes.
**Action:** Implement ARIA labels, add a Copy button for offers, and include `rel="noopener noreferrer"` on external links.
